# uniCare

## University Medical Center Digital Management System

uniCare is an AI-assisted digital healthcare management platform
designed to digitize and streamline university medical center operations.

## Technology Stack

- React
- TypeScript
- ASP.NET Core
- C#
- PostgreSQL
- Python
- FastAPI
- AI/OCR
- Docker

## Project Structure

- `frontend` - React frontend
- `backend` - ASP.NET Core Web API
- `ai-service` - Python AI service
- `docs` - Project documentation
